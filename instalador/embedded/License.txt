 # INSTALAÇÃO

 - Aplique o patch na versão MOON. DVD Edition. Não testamos em outras
   versões, mas certamente deve funcionar também nas mais recentes.

 - O seu sistema operacional deve estar em japonês para o jogo funcionar.
   No Linux/Wine, abra o jogo com o locale japonês (LC_ALL=ja_JP.UTF-8).

 - Instale o patch na pasta que tem o arquivo MOON.EXE.

 - Execute o jogo pelo arquivo MOON_PT-BR.exe.

 - Os vídeos usam o codec Xvid. Se não rodarem, instale-o pelo site oficial:
   https://www.xvid.com

 - Instale a fonte Kika-Gothic manualmente se o texto aparecer bugado.

 - Para dicas sobre as rotas e os finais, leia o Guia.txt na pasta do jogo.


 # ATENÇÃO

   O patch irá sobrescrever os arquivos originais do jogo, incluindo os vídeos
   da pasta snd. Faça um backup se quiser mantê-los.
